# MP2 Executable Builds

This folder contains pre-compiled, standalone executable builds of Machine Problem 2 for both **macOS** and **Windows**. The builds run in a resizable windowed mode at an initial resolution of 2920x2080.

## Installation & Running Instructions

### macOS
2. Download the `MacOS Build.zip` archive from this directory.
2. Extract the archive to your local machine.
3. Open the extracted folder and run the executable:
     MacOS Build/AlexBanningMP2

### Windows
2. Download the Windows Build.zip archive from this directory.
2. Extract the archive to your local machine.
3. Open the extracted folder and run the executable:
     Windows Build\AlexBanningMP2\AlexBanningMP2.exe
